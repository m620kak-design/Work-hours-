رفع التطبيق على GitHub Pages:
1) أنشئ حساباً على github.com ثم مستودعاً جديداً (Public) باسم workhours
2) اضغط Add file > Upload files وارفع كل الملفات (index.html, manifest.json, sw.js, icon-192.png, icon-512.png)
3) Settings > Pages > Branch: main > Folder: / (root) > Save
4) بعد دقيقة يظهر الرابط: https://USERNAME.github.io/workhours/
5) افتحه في كروم على الهاتف: القائمة > Add to Home screen / Install app
6) للـ APK: الصق الرابط في pwabuilder.com > Package for stores > Android

أو Netlify: افتح app.netlify.com/drop واسحب المجلد كاملاً، فتحصل على رابط فوراً.
